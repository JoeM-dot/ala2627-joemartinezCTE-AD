How the code works

01

Make a six-digit seed

Math.random() gives a value from zero up to (but not including) one. Scaling it by 900,000 and adding 100,000 makes every result a six-digit number.

function generateSeed() {
  return String(
    Math.floor(Math.random() * 900000) + 100000
  );
}
02

Make randomness repeatable

This small seeded random function updates a number using the previous value. Starting from the same seed produces the same sequence, so the maze choices repeat too.

function createRandom(seed) {
  let value = Number(seed);
  return function () {
    value = (value * 1664525 + 1013904223)
      % 4294967296;
    return value / 4294967296;
  };
}
03

Carve connected paths

The grid starts as walls. A stack walks to an unvisited cell two spaces away, opens the wall between, and backtracks when it reaches a dead end. The seeded random value picks which direction to try.

const directions = [[0, 2], [0, -2], [2, 0], [-2, 0]];
const stack = [[1, 1]];
cells[1][1] = " ";

while (stack.length) {
  const [row, column] = stack[stack.length - 1];
  const choices = findUnvisitedNeighbors(row, column, directions, cells);
  if (!choices.length) {
    stack.pop();
    continue;
  }
  const [nextRow, nextColumn, rowDelta, columnDelta] =
    choices[Math.floor(random() * choices.length)];
  carvePath(row, column, nextRow, nextColumn, rowDelta, columnDelta, cells);
  stack.push([nextRow, nextColumn]);
}
04

Mark and draw the maze

After carving, the code chooses two distant open cells for the start and exit. The renderer turns each grid value into a colored square in the preview above.
